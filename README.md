# TREND

Приватный репозиторий проекта TREND.

Начальная структура для хранения кода и документации проекта. Рабочие материалы добавляются после проверки их принадлежности TREND и отсутствия секретов.

Локальная память агента, учётные данные, выгрузки баз данных и временные файлы не включаются в репозиторий.
